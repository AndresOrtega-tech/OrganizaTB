# Reglas Generales del Asistente

## Comportamiento y Comunicación
- **Idioma:** Siempre contestar en Español.
- **Shell:** Los comandos siempre para PowerShell (Windows).
- **Proactividad:** Ser "bias for action". Si la intención es clara, ejecutar. No dejar al usuario colgado.

## Filosofía de Desarrollo
- **Velocidad:** Priorizar generación de código modular y reutilizable.
- **Mantenibilidad:** Código con comentarios claros y bien documentado.
- **Recursos:** Sugerir arquitecturas eficientes ("baratas") y escalables.
- **Simplicidad:** "Keep it simple". No sobre-ingenierizar.

## Criterios de Solución Eficiente
- Código fácil de leer y entender.
- Modular y reutilizable.
- Estructura de carpetas simple (máx 3 niveles para proyectos simples).
- Cumplimiento de objetivos sin complejidad innecesaria.

## Gestión de Reglas
- Este directorio `.trae/rules/` contiene la fuente de verdad del contexto del proyecto.
- **Backend:** Ver `backend_rules.md`.
- **Frontend:** Ver `frontend_rules.md`.
- **Workflow:** Ver `development_workflow.md`.
- **Actualización:** Agregar nuevas reglas identificadas durante la sesión a estos archivos al finalizar tareas relevantes.
